# Склад140 - Документация проекта

## 📋 Обзор проекта

**Склад140** - это кастомная WordPress тема для интернет-магазина торгового оборудования, построенная на базе WooCommerce. Тема предоставляет полнофункциональный каталог товаров с расширенной системой фильтрации, сравнением товаров, избранным и современным пользовательским интерфейсом.

### Основная информация

- **Название темы**: Склад140
- **Автор**: STRIKE
- **Сайт автора**: https://bizard.ru/
- **Версия WordPress**: 5.0+
- **Версия PHP**: 7.4+
- **Основные зависимости**: WooCommerce, ACF (Advanced Custom Fields), YITH WooCommerce Wishlist, YITH WooCommerce Compare

---

## 🎯 Ключевые функции

### 1. **Система каталога и фильтрации**
- Иерархическое дерево категорий с раскрывающимися подкатегориями
- Динамическая AJAX-фильтрация товаров по:
  - Категориям и подкатегориям
  - Цвету и материалу
  - Диапазону цен
  - Наличию на складе
  - Любым кастомным атрибутам WooCommerce
- Infinite scroll (бесконечная прокрутка) для загрузки товаров
- Живой поиск с автодополнением
- Сортировка товаров (по цене, новизне, рейтингу)

### 2. **Функционал корзины и оформления заказа**
- AJAX добавление товаров в корзину без перезагрузки страницы
- Динамическое обновление счетчиков корзины
- Кастомная страница корзины с возможностью изменения количества
- Упрощенный процесс оформления заказа
- Валидация форм с визуальной обратной связью

### 3. **Избранное и сравнение**
- Интеграция с YITH WooCommerce Wishlist
- Интеграция с YITH WooCommerce Compare
- Динамические счетчики в шапке сайта
- Кастомные AJAX обработчики для быстрого добавления/удаления

### 4. **Конструктор страниц**
- Модульная система секций для главной страницы
- 14 готовых секций (слайдер, каталог, бренды, отзывы, статьи и др.)
- Гибкая настройка через ACF

### 5. **Адаптивный дизайн**
- Полная адаптация под мобильные устройства
- Отдельные мобильные меню и модальные окна
- Оптимизированные стили для планшетов

## 🚀 Основные функции (functions.php)

### 1. Проверка товара в корзине
```php
strike_in_cart($product_id)
```
Проверяет, находится ли товар в корзине пользователя.

### 2. Получение атрибутов товара
```php
strike_first_attributes($product, $limit = 3)
```
Возвращает первые N атрибутов товара для отображения в карточке.

### 3. Фильтрация товаров
```php
s140_ajax_filter_products()
```
AJAX обработчик для динамической фильтрации товаров по категориям, атрибутам, цене.

### 4. Infinite Scroll
```php
s140_ajax_load_more_products()
```
Загрузка дополнительных товаров при прокрутке страницы.

### 5. Живой поиск
```php
theme_live_search()
```
Поиск товаров в реальном времени с автодополнением.

### 6. Работа с корзиной
```php
theme_update_cart_item_custom()
```
Обновление количества товаров в корзине через AJAX.

### 7. Wishlist и Compare
```php
custom_force_remove_from_wishlist()
custom_get_wishlist_count()
```
Кастомные обработчики для работы с избранным.

## 🛠️ Настройка и развертывание

### Требования
1. WordPress 5.0+
2. PHP 7.4+
3. MySQL 5.6+
4. WooCommerce 4.0+
5. ACF Pro
6. YITH WooCommerce Wishlist
7. YITH WooCommerce Compare

### Установка
1. Загрузите папку темы в `/wp-content/themes/`
2. Активируйте тему в админ-панели WordPress
3. Установите и активируйте необходимые плагины
4. Импортируйте настройки ACF (если есть)
5. Настройте меню в разделе "Внешний вид → Меню"
6. Настройте опции темы в "Настройки темы"

### Меню
Тема использует следующие позиции меню:
- `header` - Меню в шапке
- `footer-1` - Меню в футере-1
- `footer_categories` - Футер: категории товаров
- `footer_navigation` - Футер: навигация
- `footer_for_client` - Футер: для клиента
- `footer_for_client_mobile` - Мобильное: для клиента

## 📝 Кастомизация

### Добавление новой секции на главную
1. Создайте файл в `/template-parts/builder_page/section-name.php`
2. Добавьте поля в ACF для этой секции
3. Подключите секцию в `content-builder.php`

### Изменение стилей
1. Найдите соответствующий CSS файл в `/css/`
2. Внесите изменения в исходный SCSS/CSS
3. Минифицируйте файл
4. Очистите кэш

### Добавление нового типа страницы
1. Создайте файл `page-{slug}.php`
2. Создайте страницу в WordPress с соответствующим slug
3. Добавьте стили в `/css/`
4. Добавьте скрипты в `/js/pages/`
