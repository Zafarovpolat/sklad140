# Склад140 — Документация проекта

## Обзор

**Склад140** — кастомная WordPress-тема для интернет-магазина б/у и нового торгового оборудования (sklad140.ru). Построена на WooCommerce с кастомной фильтрацией, живым поиском, бесконечным скроллом и модульным конструктором страниц через ACF.

## Ключевые функции

### Каталог и фильтрация
- Иерархические категории с подкатегориями
- AJAX-фильтрация (категория, цвет, материал, бренд, страна, цена, наличие)
- Бесконечный скролл (infinite scroll) с защитой от дублей (`loaded_ids`)
- Сортировка: по цене (↑↓), дате, рейтингу
- Товары «в наличии» всегда выше товаров «не в наличии» (posts_clauses hook)

### Поиск
- Живой поиск (AJAX, debounce 300ms, мин. 2 символа)
- Мягкий поиск: каждое слово ≥2 символов ищется через LIKE AND в `post_title`
- Ранжирование: совпадение в начале названия → score 100, внутри → 50
- Десктопная модалка + мобильная версия с карточками товаров
- История поиска в localStorage
- Кнопка Enter → переход на `/shop/?s=запрос`
- Иконка лупы → переход на `/shop/?s=запрос`

### Корзина и заказ
- AJAX добавление без перезагрузки
- Динамические счётчики в шапке
- Обновление количества через AJAX с расчётом скидок
- Упрощённое оформление (необязательные поля: фамилия, email, город, индекс)

### Формы
- Единый AJAX endpoint `s140_submit_form` для всех форм
- Типы: «Перезвонить мне», «Купить в 1 клик», «Подобрать аналог», «Связаться», «Отклик на вакансию»
- Валидация на фронте (`modal-validation.js`) + на бэкенде
- Honeypot-защита от ботов
- Лог заявок в `wp_options` (последние 200)

### Избранное и сравнение
- YITH WooCommerce Wishlist + кастомные AJAX обработчики
- YITH WooCommerce Compare + парсинг cookie
- Динамические счётчики в шапке

### Конструктор страниц (ACF)
- 14 секций для главной (слайдер, каталог, бренды, отзывы, статьи и др.)
- Настройка через ACF опции темы

## Известные особенности и решения

| Проблема | Причина | Решение |
|----------|---------|---------|
| 403 на живой поиск | W3TC кэширует stale nonce | Убран `check_ajax_referer()` — endpoint публичный read-only |
| Дубли товаров при скролле | Повторная загрузка тех же ID | `loaded_ids` в AJAX запросе + `post__not_in` |
| Медленная админка | Плагины с тяжёлыми AJAX (Yoast SEO) | Отключение Yoast фоновых задач |
| Боты грузят сервер | meta-externalagent спамит SQL через strikedev | Блокировка через .htaccess + rate-limiting |
| Атрибуты не в карточке | `is_visible=0` из bulk-editor | Хук `woocommerce_display_product_attributes` показывает все |
| Поиск слишком строгий | Стандартный WP-поиск | Мягкий поиск: LIKE AND по каждому слову |
